# 🌳 Predicción de Préstamos mediante Árbol de Decisión

## Descripción

Este proyecto implementa un modelo de Inteligencia Artificial basado en un Árbol de Decisión para predecir la aprobación o rechazo de solicitudes de préstamo utilizando un conjunto de datos público de Kaggle.

El desarrollo incluye el proceso completo de análisis exploratorio, preprocesamiento de datos, entrenamiento del modelo y evaluación mediante diferentes métricas de clasificación.

---

## Objetivos

- Analizar un conjunto de datos de solicitudes de préstamo.
- Implementar un Árbol de Decisión utilizando Scikit-learn.
- Evaluar el desempeño del modelo.
- Interpretar las decisiones del algoritmo mediante la visualización del árbol.

---

## Dataset

- Fuente: Kaggle
- Registros: 614
- Variables: 13
- Variable objetivo:
  - Loan_Status

---

## Tecnologías utilizadas

- Matplotlib
